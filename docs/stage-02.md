# 阶段二验收记录

日期：2026-11-02。阶段：数据库和基础业务数据。

## 已实现

- 使用 SQLAlchemy 2 异步 ORM 与 SQLite，默认数据库位于 `backend/data/ecommerce.db`。
- 数据库位置由代码路径计算，不依赖启动工作目录；可通过 `DATABASE_URL` 覆盖。
- 建立用户、商品、订单和订单明细表，包含启用的 SQLite 外键、唯一约束、数量/金额检查约束和 ORM 关系。
- 提供两名演示用户、四种商品和三笔订单；包含有库存和零库存商品，订单覆盖已发货、已收货和已付款状态。
- `python -m app.scripts.init_db` 创建表并补齐缺失的演示行；支持重复运行，不重置现有业务数据。
- README 已更新为使用 `ecommerce` Conda 环境，并说明首次数据库初始化和日常启动步骤。

## 验收标准
